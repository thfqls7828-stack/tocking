# Tocking 기획·디자인

## Routing

- 제품 요구사항, 사용자 시나리오, MVP 범위는 `plan-tocking-product`를 사용한다.
- 화면 구조, 상태별 UI, 토론 UX 설계는 `design-tocking-ui`를 사용한다.
- 공통 테마, shadow, width, height, spacing, radius 등은 `manage-tocking-core`를 사용한다.

넓은 요청은 먼저 작은 작업으로 쪼개고, 각 산출물을 `AGENTS.md`에 남긴다.
