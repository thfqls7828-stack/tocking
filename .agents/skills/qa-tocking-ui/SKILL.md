# Tocking UI QA

## Overview

Tocking의 화면이 토론 앱으로 제대로 작동하는지 검증한다. API 정확성보다
사용자 경험, 레이아웃, 상태 표현을 우선 확인한다.

## Checklist

- Tocking이 토론 앱임이 첫 화면에서 드러나는가
- 주제, 찬반 관점, 사용자 의견, AI 보조 정보가 구분되는가
- 로딩, 빈 상태, 오류 상태가 표시되는가
- 모바일과 데스크톱에서 텍스트와 버튼이 겹치지 않는가
- core 토큰을 무시한 임의 스타일이 늘어나지 않았는가
- 사용자가 의견 작성까지 자연스럽게 이동하는가

## Output

심각도 높은 UI 문제, 검증한 화면 크기, 확인하지 못한 상태, 수정 추천을 짧게
정리한다. 반복 규칙은 `AGENTS.md` 갱신 후보로 제안한다.
