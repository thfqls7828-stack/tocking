# Tocking 도메인 모델

## Overview

Tocking의 핵심 도메인 규칙과 상태 모델을 정의한다. UI나 API 구현이 아니라
토론 앱의 의미 있는 데이터와 규칙을 다룬다.

## Domain Scope

- 추천 토론 주제
- 핵심 쟁점
- 찬성/반대/중립 관점
- 사용자 의견
- AI 보조 요약과 질문
- 토론 참여 상태
- API 실패와 비어 있는 주제 상태의 도메인 표현

## Rules

- 도메인은 UI 프레임워크와 API SDK에 의존하지 않는다.
- 외부 응답 DTO와 도메인 엔티티를 구분한다.
- 상태 전이는 테스트 가능한 작은 규칙으로 둔다.
- 도메인 결정은 `AGENTS.md`에 요약한다.
