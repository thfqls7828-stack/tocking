# Tocking UI 디자인

## Overview

Tocking의 화면과 상호작용을 설계한다. 코드 구현은 하지 않고, 구현자가 바로
옮길 수 있는 화면 구조와 상태를 정의한다.

## Workflow

1. `AGENTS.md`와 필요한 제품 기획 내용을 확인한다.
2. 화면의 목적과 사용자 행동을 하나로 좁힌다.
3. 정보 구조, 주요 컴포넌트, 상태별 UI를 정의한다.
4. 토론 주제, 찬반 관점, 사용자 의견, AI 보조 정보가 구분되도록 설계한다.
5. core 디자인 토큰이 필요하면 `manage-tocking-core`로 넘긴다.
6. 구현 대상은 `build-tocking-ui`가 처리할 수 있게 명확히 남긴다.

## Design Checklist

- 첫 화면에서 Tocking과 토론 목적이 드러나는가
- 주제와 의견, AI 보조 정보가 혼동되지 않는가
- 로딩, 빈 상태, 오류 상태가 있는가
- 모바일에서 긴 텍스트와 버튼이 겹치지 않는가
- 불필요한 랜딩 페이지 대신 실제 앱 화면을 우선하는가
